## OpenCode 连接测试排障

2026-10-20 复现正式 `/api/ai/test` 的 502，确认两处问题：Workers 不支持 `redirect: 'error'`，请求在发出前就因参数无效失败；相同配置在 Node 发出请求后，上游另返回 `400 MissingSessionID`，要求提供 `x-opencode-session`。

改为 `redirect: 'manual'`，由 SDK 检查非 2xx 响应，禁止携带密钥自动跳转。workerd 回归先复现与线上一致的 Invalid redirect value 异常，修改后通过；另验证 307 响应只访问原地址。运行时测试使用随 CLI 固定的 Miniflare / workerd，兼容日期为其支持的 2026-10-19。

共享模型工厂仅对 `opencode.ai` 发送应用 User-Agent 和模型会话标识；服务端按账号、连接测试/导师对话/出题范围生成稳定摘要。请求头在 fetch 边界设置，避免 AI SDK 7 用通用 User-Agent 覆盖应用标识。Cookie 和 API Key 均不作为模型会话标识。连接测试失败时显示上游 HTTP 状态，不返回原始错误响应或密钥。

正式重新执行原始连接测试已返回 HTTP 200、`ok: true`，耗时约 3.1 秒。临时诊断分支、会话文件及解密后的诊断密钥已清理。
