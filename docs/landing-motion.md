与原站的区别：这是教育产品官网，不复制代理机构的客户案例、客户证言或博客。画廊使用自制教育图形，产品影片使用自己的界面录制，没有声称拥有原站商业影片。原生滚动替代 Lenis；没有额外安装滚动或动画引擎。工作台内部导航保留原交互，不套用官网长转场。

浏览器检查：390px 中文与英文文档宽度均为 390px；手机菜单展开与 Escape 收起；官网 → 工作台与返回官网，观察白色遮罩和入场词动画。减少动态偏好在加载前与页面运行时切换均验证；Motion 14 默认 hook 不响应运行中变化，改用 React useSyncExternalStore 订阅，确认视频暂停、词 transform 清除。所有浏览器模拟设置在检查结束时恢复。
